# Campsite Reservation System
## CMPUT 301 - Group Mbappe.

This is a CMPUT 301 group project at the University of Alberta.

Our application allows users to discover campsites, view campsite information, and participate in a lottery-based reservation system. Campsite owners can register their campsites, manage listings, and create lotteries for reservations. 

The application uses Kotlin as its primary coding language along with a Firebase Database.

## Features
The application currently has the following functionality:

### User Accounts
- Sign in as a guest
- View and update user profile information
- Access campsite browsing and owner features
  
### Campsite Browsing
- Browse list of published campsites
- Search campsites by name or location
- View campsite summaries, such as location, max occupancy, and average rating.
- View detailed descriptions, amenities, rules, pricing, and availability.
- Display campsite photos
  
### Campsite Management
- Register new campsites
- Add campsite information
- Publish campsites for other users to discover
- View and manage owned campsites
  
### Lottery and Reservations
- Create lotteries for registered campsites
- Set registration periods and available booking dates
- Display lottery availability
